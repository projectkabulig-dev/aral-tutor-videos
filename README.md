# ARAL Gain Tracker: tutor video guide

Project KABULIG, Schools Division Office of Romblon.

A static site (no build step). Files:

- `index.html`: the page (instructions first, then the 10 topics)
- `media/topicNN.mp4`: the videos (1920x1080, H.264 and AAC, English voice)
- `media/topicNN.vtt`: English captions
- `media/topicNN.jpg`: posters

Publish: create a repository named `aral-tutor-videos`, upload these files, then Settings > Pages > Deploy from a branch > main > /(root).
The page will be at https://projectkabulig-dev.github.io/aral-tutor-videos/ (the link inside the ARAL Gain Tracker app points here).
